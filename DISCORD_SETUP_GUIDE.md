## 🤖 **Bot Setup**

### **1. MEE6 (Level System & Moderation)**
**Purpose:** Gamification, auto-moderation

**Setup:**
1. Invite MEE6: https://mee6.xyz/
2. Enable Leveling plugin
3. Set XP rewards:
   - 15-25 XP per message
   - Level 5: Dragon Initiate role
   - Level 10: Dragon Seeker role
   - Level 20: Dragon Scholar role
   - Level 50: Dragon Sage role

4. Enable Moderation:
   - Auto-delete spam
   - Auto-mute bad words
   - Warn system (3 warns = kick)

5. Custom Commands:
   ```
   !chapters - Show available chapters
   !quiz - Link to dragon quiz
   !premium - Show premium benefits
   !support - Contact support
   ```

### **2. Dyno (Advanced Moderation)**
**Purpose:** Advanced auto-mod, welcome messages

**Setup:**
1. Invite Dyno: https://dyno.gg/
2. Set welcome message:
   ```
   Welcome {user} to the Dragon Bible community! 🐉
   
   🎯 Take the quiz: [link]
   📖 Read free chapters: [link]
   💬 Introduce yourself in #introductions
   
   Remember your wings!
   ```

3. Auto-role assignment:
   - New members → @Seeker role

4. Reaction roles in #rules:
   - React with ✅ to accept rules → unlock channels

### **3. YAGPDB (Custom Commands & Automations)**
**Purpose:** Advanced custom commands

**Setup:**
1. Invite YAGPDB: https://yagpdb.xyz/
2. Custom commands:
   ```
   !verse <book> <chapter> <verse>
   → Returns specific verse from Dragon Bible
   
   !random
   → Random verse of the day
   
   !archetype <type>
   → Info about dragon archetype
   ```

### **4. Statbot (Analytics)**
**Purpose:** Track server growth, engagement

**Setup:**
1. Invite Statbot: https://statbot.net/
2. View:
   - Member growth
   - Message activity
   - Most active channels
   - Most active members

## 🛡️ **Moderation Guidelines**

### **Rules:**
```
1. Be respectful - No harassment, hate speech, or discrimination
2. Stay on topic - Use appropriate channels
3. No spam - Self-promotion only in designated channels
4. No NSFW - Keep content PG-13
5. Respect privacy - Don't share personal info
6. Follow Discord ToS
7. Moderators have final say
```

### **Warning System:**
- **Warning 1:** Verbal warning
- **Warning 2:** 24-hour mute
- **Warning 3:** 7-day ban
- **Warning 4:** Permanent ban

### **Auto-Moderation:**
- Ban certain words
- Delete messages with @everyone/@here (except admins)
- Rate limit to prevent spam
- New account restrictions (must be 7+ days old)
