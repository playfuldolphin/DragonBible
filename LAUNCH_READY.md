## 🆘 TROUBLESHOOTING

### "Payments not working"
→ Check `.env` has correct keys
→ Verify webhook URL in Stripe
→ Check browser console for errors

### "Firebase auth failing"
→ Ensure scripts loaded (check network tab)
→ Verify config in `auth.js`
→ Check domain authorized in Firebase

### "Server won't start"
→ Run `npm install` first
→ Check `.env` exists
→ Verify port 3000 not in use
